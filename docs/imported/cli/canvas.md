# dendrite canvas

Interactive writing canvas and Penpot UI direct creative action bridge

## Category

Postsynaptic Effectors & Actuation

## Aliases

- `creative-canvas`
- `interactive-canvas`
- `pcontext-canvas`

## Subcommands

| Subcommand | Description |
| :--- | :--- |
| `actions` | List available creative canvas actions |
| `dispatch` | Dispatch canvas action to Penpot |
| `relate` | Relate canvas element to Plane ticket |
| `sync` | Synchronize canvas state |
| `update-state` | Update canvas element state |

## Flags

None

## Examples

```bash
dendrite canvas actions
```
